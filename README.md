# Multi-Model AnswerBoard – AI Fiesta

## Capstone Project

This repository contains the complete capstone project with three modules:

### Module 1 – Data Pipeline
Location: `data_pipeline/`

A web scraping and data processing pipeline that collects book data, cleans the data, stores it in SQLite, and performs SQL-based analysis.

### Module 2 – Analytics
Location: `analytics/`

An analytics and machine learning pipeline using the Titanic dataset, including EDA, preprocessing, classification models, imbalance handling, hyperparameter tuning, and regression analysis.

### Module 3 – Support Assistant
Location: `support_assistant/`

An offline GenAI-style Zepto customer support assistant using document embeddings, ChromaDB retrieval, LangGraph orchestration, Pydantic structured output, and FastAPI.
